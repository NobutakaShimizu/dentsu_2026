# dentsu_2026

Slidev project (based on LA26s). スライド内容は [jcca2025](https://github.com/NobutakaShimizu/jcca2025) と同じです。

To start the slide show:

- `npm install`
- `npm run dev`
- visit <http://localhost:3030>

Edit the [slides.md](./slides.md) to see the changes.

## Deploy (GitHub Pages)

`main` への push、または Actions の **Deploy pages** → **Run workflow** で自動デプロイされます。

1. GitHub リポジトリの **Settings → Pages → Source** を **GitHub Actions** にする
2. `main` に push する

公開 URL（想定）: https://nobutakashimizu.github.io/dentsu_2026/

Learn more about Slidev at the [documentation](https://sli.dev/).
